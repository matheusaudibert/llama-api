## Base URL

The base URL is the domain where you host the API, for example `https://api.yourdomain.com`. In this documentation's playground, edit the `host` field to point to your instance.

<Info>
  The API is made to be self-hosted. To use the hosted instance at `https://llamaapi.audibert.dev` instead, ask for an API key by [opening an issue on GitHub](https://github.com/matheusaudibert/llama-api/issues/new).
</Info>

## Authentication

Every endpoint except `GET /health` requires the `X-API-Key` header, set to the `API_KEY` variable configured on the API.

```bash
curl https://api.yourdomain.com/auth/device \
  -X POST \
  -H "X-API-Key: your-key"
```

Without the header, or with a wrong key, the response is `401`.

<Warning>
  The API key lets anyone start logins and read accounts. Keep it only on your bot's server, never in source code or clients.
</Warning>

## Typical flow

1. `POST /auth/device`: starts the login and returns the Epic link.
2. `GET /auth/{session_id}`: poll until `completed`.
3. `GET /accounts/{session_id}/summary` and `GET /accounts/{session_id}/locker`: read the data.
4. `POST /render/{category}`: optional, renders the locker images from the saved items.
5. `DELETE /auth/{session_id}`: ends the session.

See each endpoint in the sidebar and the full flow in [Login flow](/guides/login-flow).

## OpenAPI spec

The API itself serves the spec at `/openapi.json` and a Swagger UI at `/docs`. Use the spec to generate types for your bot.

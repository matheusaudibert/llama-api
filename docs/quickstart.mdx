## Prerequisites

- Python 3.12 or newer, or Docker
- An Epic Games account to test with

<Steps>
  <Step title="Clone the repository and install the dependencies">
    ```bash
    git clone https://github.com/matheusaudibert/llama-api.git
    cd llama-api
    python -m venv .venv
    source .venv/bin/activate  # Windows: .venv\Scripts\activate
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Configure the environment">
    Copy the example file:

    ```bash
    cp .env.example .env
    ```

    Fill in `.env`. The API does not start without these four variables:

    - `API_KEY`: a random key your bot will send. Generate one with `python -c "import secrets; print(secrets.token_urlsafe(32))"`.
    - `EPIC_SWITCH_CLIENT`, `EPIC_IOS_CLIENT` and `EPIC_EOS_CLIENT`: the Epic OAuth clients, as base64 `client_id:client_secret`, for the Nintendo Switch client, `fortniteIOSGameClient` and `fortnitePCGameClient`. Take them from the [Epic auth clients list](https://github.com/MixV2/EpicResearch/blob/main/docs/auth/auth_clients.md).
  </Step>
  <Step title="Start the server">
    ```bash
    uvicorn api.main:app --port 8000 --env-file .env
    ```

    Wait for the `Catalog loaded: ... cosmetics` line in the log. The interactive FastAPI docs are at `http://localhost:8000/docs`.
  </Step>
  <Step title="Start a login">
    ```bash
    curl -X POST http://localhost:8000/auth/device -H "X-API-Key: $API_KEY"
    ```

    ```json Response
    {
      "session_id": "8M4-85Ra3sMk5gmMyvm__k_54_fGdHyo",
      "verification_url": "https://www.epicgames.com/activate?userCode=RSHBCWPX",
      "expires_in": 600
    }
    ```

    Open `verification_url` in the browser and authorize with the Epic account.
  </Step>
  <Step title="Check the status">
    ```bash
    curl http://localhost:8000/auth/YOUR_SESSION_ID -H "X-API-Key: $API_KEY"
    ```

    When `status` is `completed`, the account is logged in.
  </Step>
  <Step title="Read the locker">
    ```bash
    curl http://localhost:8000/accounts/YOUR_SESSION_ID/locker -H "X-API-Key: $API_KEY"
    ```
  </Step>
  <Step title="End the session">
    ```bash
    curl -X DELETE http://localhost:8000/auth/YOUR_SESSION_ID -H "X-API-Key: $API_KEY"
    ```
  </Step>
</Steps>

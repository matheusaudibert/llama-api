## Pré-requisitos

- Python 3.12 ou mais novo, ou Docker
- Uma conta Epic Games para testar

<Steps>
  <Step title="Clone o repositório e instale as dependências">
    ```bash
    git clone https://github.com/matheusaudibert/llama-api.git
    cd llama-api
    python -m venv .venv
    source .venv/bin/activate  # Windows: .venv\Scripts\activate
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Configure o ambiente">
    Copie o arquivo de exemplo:

    ```bash
    cp .env.example .env
    ```

    Preencha o `.env`. A API não inicia sem estas quatro variáveis:

    - `API_KEY`: uma chave aleatória que o seu bot vai enviar. Gere com `python -c "import secrets; print(secrets.token_urlsafe(32))"`.
    - `EPIC_SWITCH_CLIENT`, `EPIC_IOS_CLIENT` e `EPIC_EOS_CLIENT`: os clientes OAuth da Epic, em base64 `client_id:client_secret`, do cliente do Nintendo Switch, do `fortniteIOSGameClient` e do `fortnitePCGameClient`. Pegue na [lista de clientes da Epic](https://github.com/MixV2/EpicResearch/blob/main/docs/auth/auth_clients.md).
  </Step>
  <Step title="Inicie o servidor">
    ```bash
    uvicorn api.main:app --port 8000 --env-file .env
    ```

    Espere a linha `Catalog loaded: ... cosmetics` no log. A documentação interativa do FastAPI fica em `http://localhost:8000/docs`.
  </Step>
  <Step title="Inicie um login">
    ```bash
    curl -X POST http://localhost:8000/auth/device -H "X-API-Key: $API_KEY"
    ```

    ```json Resposta
    {
      "session_id": "8M4-85Ra3sMk5gmMyvm__k_54_fGdHyo",
      "verification_url": "https://www.epicgames.com/activate?userCode=RSHBCWPX",
      "expires_in": 600
    }
    ```

    Abra `verification_url` no navegador e autorize com a conta Epic.
  </Step>
  <Step title="Confira o status">
    ```bash
    curl http://localhost:8000/auth/SEU_SESSION_ID -H "X-API-Key: $API_KEY"
    ```

    Quando `status` for `completed`, a conta está logada.
  </Step>
  <Step title="Leia o locker">
    ```bash
    curl http://localhost:8000/accounts/SEU_SESSION_ID/locker -H "X-API-Key: $API_KEY"
    ```
  </Step>
  <Step title="Encerre a sessão">
    ```bash
    curl -X DELETE http://localhost:8000/auth/SEU_SESSION_ID -H "X-API-Key: $API_KEY"
    ```
  </Step>
</Steps>

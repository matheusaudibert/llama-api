`GET /accounts/{session_id}/locker` devolve todos os cosméticos da conta, separados por categoria.

## Categorias

| Campo | Conteúdo |
|---|---|
| `skins` | Trajes (`cid_*`, `character_*`) |
| `backpacks` | Mochilas (`bid_*`) |
| `pickaxes` | Picaretas (`pickaxe_*`) |
| `emotes` | Emotes (`eid_*`) |
| `gliders` | Asas-deltas e guarda-chuvas |
| `wraps` | Envelopamentos |
| `sprays` | Sprays |
| `others` | Tudo que não se encaixa acima (músicas, telas de carregamento, etc.) |
| `banners` | Banners do perfil |

`counts` traz a quantidade de itens por categoria, útil para embeds de resumo.

## Formato de um item

```json
{
  "id": "cid_028_athena_commando_f",
  "name": "Renegade Raider",
  "name_pt": "Saqueadora Renegada",
  "rarity": "Mythic",
  "series": null,
  "type": "outfit",
  "images": {
    "icon": "https://fortnite-api.com/images/cosmetics/br/cid_028_athena_commando_f/icon.png",
    "small_icon": "https://fortnite-api.com/images/cosmetics/br/cid_028_athena_commando_f/smallicon.png",
    "featured": "https://fortnite-api.com/images/cosmetics/br/cid_028_athena_commando_f/featured.png"
  },
  "owned_styles": ["Mat1", "Mat2"],
  "is_exclusive": true,
  "is_mythic": true,
  "in_catalog": true
}
```

`name_pt` é o nome em português do Brasil, do catálogo em português do fortnite-api.com. É igual ao `name` quando o item ainda não tem tradução. Os nomes dos OGs também são traduzidos (`OG Saqueadora Renegada`).

## Raridade e ordenação

`rarity` vem do fortnite-api (`Common`, `Uncommon`, `Rare`, `Epic`, `Legendary` ou uma série, como `Icon Series`, `MARVEL SERIES` e `DC SERIES`). Itens míticos viram `Mythic`, independente da raridade no jogo, e têm `is_mythic: true`.

## Míticos e OGs

Um item é mítico em dois casos:

1. **Itens que voltaram à loja, mas os donos originais têm um estilo exclusivo.** Só contam como míticos com esse estilo em `owned_styles`. O nome vira `OG …` e `images.icon` passa a mostrar o estilo.

   | Item | Estilo OG | Tag |
   |---|---|---|
   | Renegade Raider | Black & Gold | `Mat3` |
   | Aerial Assault Trooper | Black & Gold | `Stage2` |
   | The Paradigm | Reality Warrior | `Mat3` |
   | Ghoul Trooper | Pink | `Mat3` |
   | Skull Trooper | Purple Glow | `Mat1` |
   | Fishstick | World Cup | `Stage3` |

   Um Renegade Raider comprado na loja depois de dezembro de 2024 aparece como item normal.

2. **Itens raros de uma lista fixa** (passes de batalha antigos, promoções, torneios: Black Knight, Travis Scott, Floss…) que **não foram vendidos na loja nos últimos 2 anos**. Quando um item volta à loja, ele deixa de ser mítico sozinho, pelo histórico da loja no fortnite-api.

Cada lista já vem ordenada:

1. Por raridade: Mythic, Legendary, séries (Dark, Slurp, Star Wars, Marvel, Lava, Frozen, Gaming Legends, Shadow, Icon, DC), Epic, Rare, Uncommon, Common.
2. Entre os míticos, pela ordem dos itens mais raros (Renegade Raider, Ghoul Trooper…).
3. Por nome.

`is_exclusive` marca um grupo pequeno de itens muito raros (Renegade Raider, Aerial Assault Trooper, Ghoul Trooper, Skull Trooper, Omega, Fishstick e The Paradigm), útil para um destaque especial.

## Itens equipados

`GET /accounts/{session_id}/equipped` devolve o que o jogador tem equipado agora, no visual ativo. Os presets salvos não entram.

```json
{
  "skin": { "id": "character_fastrabbit", "name": "Dueling Dragons Jackie", "name_pt": "Jaqueline do Duelo de Dragões", "rarity": "Epic", "styles": [], "...": "..." },
  "backpack": null,
  "pickaxe": { "id": "pickaxe_saltybrim_pin", "name": "Sonic Ring", "...": "..." },
  "glider": { "...": "..." },
  "contrail": { "...": "..." },
  "shoes": null,
  "aura": { "...": "..." },
  "emotes": [{ "id": "eid_fruitfire", "name": "Lil' Station Wagon", "styles": ["Stage9"], "...": "..." }],
  "wraps": [{ "...": "..." }],
  "banner": { "...": "..." },
  "lobby_music": null,
  "loading_screen": null
}
```

- Cada item tem os mesmos `name`, `rarity`, `images` e `is_mythic` do locker, mais `styles`: as tags dos estilos escolhidos naquele item. Um estilo OG equipado (Renegade Raider `Mat3`…) torna o item mítico, com o nome `OG …` e a imagem do estilo.
- Espaço vazio vem como `null`. `emotes` e `wraps` são listas na ordem dos espaços, sem os vazios.
- Os dados vêm do Locker Service do Fortnite, então mudam assim que o jogador troca o visual no jogo.

## Imagens

As URLs em `images` apontam direto para o CDN do fortnite-api.com.

Para uma imagem pronta do locker, use `POST /render/{category}`, com `category` igual a `skins`, `backpacks`, `pickaxes`, `gliders`, `emotes` ou `mythics`. A `mythics` junta os itens míticos de todas essas categorias, com os trajes primeiro. Ela devolve um PNG com um cabeçalho (ícone da categoria, "LOCKER", nome da categoria com a quantidade, logo da Epic Games, nick e data) e uma grade com um card por item, com o fundo da raridade e o nome.

A rota não usa sessão. Envie os itens que você salvou do `/locker`: dá para gerar e regerar a imagem a qualquer momento, sem um novo login.

```bash
curl -X POST https://api.seudominio.com/render/skins \
  -H "X-API-Key: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"display_name": "Jogador123", "items": [{"id": "cid_028_athena_commando_f", "owned_styles": ["Mat3"]}]}' \
  -o skins.png
```

- Pode mandar os itens de todas as categorias juntos: só os da categoria pedida entram na imagem.
- Envie `owned_styles`: sem ele, os OGs (Renegade Raider, Ghoul Trooper, Skull Trooper…) não são reconhecidos.
- Envie `"language": "pt-BR"` para os nomes dos itens em português nos cards. O padrão é `en`.
- Sem nenhum item da categoria, a resposta é `422`.
- Contas grandes são reduzidas para caber em 2048 px de largura. A primeira imagem de uma conta grande pode levar alguns segundos, porque os ícones são baixados e ficam em cache.

<Tip>
  Guarde as imagens baixadas em cache local pelo `id`. Mas só faça cache quando a resposta for `200`: itens recém-lançados podem ainda não ter imagem.
</Tip>

## Itens novos

Quando a Epic lança uma skin, ela aparece no locker assim que o jogador a tiver, porque a lista vem direto do perfil da conta. Nome, raridade e imagem dependem do fortnite-api.com:

- Se o item ainda não estiver no catálogo em memória, a API busca só aquele item na hora.
- Se o fortnite-api.com ainda não tiver o item, ele vem com `in_catalog: false`, `name` igual ao `id` e `rarity: "Common"`. Mostre um placeholder nesse caso.

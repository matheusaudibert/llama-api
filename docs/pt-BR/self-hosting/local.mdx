---
title: "Docker local"
description: "Rode a API com Docker na sua máquina ou em qualquer servidor."
icon: "docker"
---

```bash
docker build -t llama-api .
docker run -d --name llama-api \
  -p 8000:8000 \
  -e API_KEY="cole-a-chave-aqui" \
  --restart unless-stopped \
  llama-api
```

Confira se subiu:

```bash
curl http://localhost:8000/health
```

## Variáveis de ambiente

| Variável | Obrigatória | Padrão | Descrição |
|---|---|---|---|
| `API_KEY` | Sim | | Chave que o bot envia no header `X-API-Key` |
| `CATALOG_REFRESH_SECONDS` | Não | `21600` | Intervalo de recarga do catálogo do fortnite-api.com |
| `LOG_LEVEL` | Não | `INFO` | `DEBUG`, `INFO`, `WARNING` ou `ERROR`. `DEBUG` também registra as chamadas a `/health` |
| `LOG_FORMAT` | Não | `text` | `text` para linhas `chave=valor`, `json` para um objeto JSON por linha |
| `PUBLIC_URL` | Não | host da requisição | URL base usada em `images.background`, ex: `https://api.seudominio.com`. Defina quando um proxy muda o host |

## Atualizar a documentação da API

Os arquivos `docs/openapi.json` (inglês) e `docs/pt-BR/openapi.json` (português) são gerados a partir do código. Depois de mudar um endpoint ou modelo, rode na raiz do repositório:

```bash
python scripts/export_openapi.py
```

As descrições no código ficam em inglês. A versão em português usa as traduções de `scripts/openapi_pt.py`: o script avisa quando falta alguma.

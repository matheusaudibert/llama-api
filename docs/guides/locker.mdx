`GET /accounts/{session_id}/locker` returns every cosmetic on the account, split by category.

## Categories

| Field | Content |
|---|---|
| `skins` | Outfits (`cid_*`, `character_*`) |
| `backpacks` | Back blings (`bid_*`) |
| `pickaxes` | Pickaxes (`pickaxe_*`) |
| `emotes` | Emotes (`eid_*`) |
| `gliders` | Gliders and umbrellas |
| `wraps` | Wraps |
| `sprays` | Sprays |
| `others` | Everything else (music, loading screens, etc.) |
| `banners` | Profile banners |

`counts` has the number of items per category, handy for summary embeds.

## Item format

```json
{
  "id": "cid_028_athena_commando_f",
  "name": "Renegade Raider",
  "name_pt": "Saqueadora Renegada",
  "rarity": "Mythic",
  "series": null,
  "type": "outfit",
  "images": {
    "icon": "https://fortnite-api.com/images/cosmetics/br/cid_028_athena_commando_f/icon.png",
    "small_icon": "https://fortnite-api.com/images/cosmetics/br/cid_028_athena_commando_f/smallicon.png",
    "featured": "https://fortnite-api.com/images/cosmetics/br/cid_028_athena_commando_f/featured.png",
    "background": "https://api.yourdomain.com/backgrounds/mythic.png"
  },
  "owned_styles": ["Mat1", "Mat2"],
  "is_exclusive": true,
  "is_mythic": true,
  "from_shop": true,
  "estimated_price": 1200,
  "in_catalog": true
}
```

`name_pt` is the name in Brazilian Portuguese, from the fortnite-api.com Portuguese catalog. It is the same as `name` when the item has no translation yet. OG names are translated too (`OG Saqueadora Renegada`).

## Rarity and sorting

`rarity` comes from fortnite-api (`Common`, `Uncommon`, `Rare`, `Epic`, `Legendary` or a series, such as `Icon Series`, `MARVEL SERIES` and `DC SERIES`). Mythic items become `Mythic`, whatever their in-game rarity, and have `is_mythic: true`.

## Mythics and OGs

An item is mythic in two cases:

1. **Items that came back to the shop, but the original owners have an exclusive style.** They only count as mythic with that style in `owned_styles`. The name becomes `OG …` and `images.icon` shows the style.

   | Item | OG style | Tag |
   |---|---|---|
   | Renegade Raider | Black & Gold | `Mat3` |
   | Aerial Assault Trooper | Black & Gold | `Stage2` |
   | The Paradigm | Reality Warrior | `Mat3` |
   | Ghoul Trooper | Pink | `Mat3` |
   | Skull Trooper | Purple Glow | `Mat1` |
   | Fishstick | World Cup | `Stage3` |

   A Renegade Raider bought in the shop after December 2024 shows up as a normal item.

2. **Rare items from a fixed list** (old battle passes, promotions, tournaments: Black Knight, Travis Scott, Floss…) that **were not sold in the shop in the last 2 years**. When an item comes back to the shop, it stops being mythic on its own, based on the fortnite-api shop history.

Every list is already sorted:

1. By rarity: Mythic, Legendary, series (Dark, Slurp, Star Wars, Marvel, Lava, Frozen, Gaming Legends, Shadow, Icon, DC), Epic, Rare, Uncommon, Common.
2. Among mythics, by the order of the rarest items (Renegade Raider, Ghoul Trooper…).
3. By name.

`is_exclusive` flags a small group of very rare items (Renegade Raider, Aerial Assault Trooper, Ghoul Trooper, Skull Trooper, Omega, Fishstick and The Paradigm), useful for a special highlight.

## Shop items and estimated value

`from_shop` is `true` when the item was sold in the item shop at least once, from the fortnite-api.com shop history. Battle pass, pack, promotional and event items are `false`.

`estimated_price` is the estimated shop price in V-Bucks, only for shop items. fortnite-api has no price history, so it comes from the usual shop price for the item type and rarity. Sales, bundles and collab prices are not taken into account, so treat it as an estimate, not what the player paid.

| Type | Common / Uncommon | Rare | Epic | Legendary | Series |
|---|---|---|---|---|---|
| Outfit | 800 | 1200 | 1500 | 2000 | 1500 |
| Back bling | 200 | 300 | 400 | 500 | 400 |
| Pickaxe | 500 | 800 | 1200 | 1500 | 800 |
| Glider | 500 | 800 | 1200 | 1500 | 1200 |
| Emote | 200 | 500 | 800 | 800 | 500 |
| Wrap / contrail | 300 | 500 | 700 | 700 | 500 |
| Music | 200 | 200 | 200 | 200 | 200 |

Other types (sprays, loading screens, banners…) have `estimated_price: null`. Mythic items are priced by their original rarity.

The locker response also has a `shop` summary:

```json
"shop": {
  "counts": { "skins": 21, "backpacks": 17, "pickaxes": 14, "emotes": 18, "gliders": 2, "wraps": 8, "sprays": 1, "others": 11, "banners": 0 },
  "estimated_vbucks": 55000
}
```

## Equipped items

`GET /accounts/{session_id}/equipped` returns what the player has equipped right now, in the active loadout. Saved presets are not included.

```json
{
  "skin": { "id": "character_fastrabbit", "name": "Dueling Dragons Jackie", "name_pt": "Jaqueline do Duelo de Dragões", "rarity": "Epic", "styles": [], "...": "..." },
  "backpack": null,
  "pickaxe": { "id": "pickaxe_saltybrim_pin", "name": "Sonic Ring", "...": "..." },
  "glider": { "...": "..." },
  "contrail": { "...": "..." },
  "shoes": null,
  "aura": { "...": "..." },
  "emotes": [{ "id": "eid_fruitfire", "name": "Lil' Station Wagon", "styles": ["Stage9"], "...": "..." }],
  "wraps": [{ "...": "..." }],
  "banner": { "...": "..." },
  "lobby_music": null,
  "loading_screen": null
}
```

- Each item has the same `name`, `rarity`, `images` and `is_mythic` as in the locker, plus `styles`: the style tags selected on that item. An equipped OG style (Renegade Raider `Mat3`…) makes the item mythic, with the `OG …` name and image.
- An empty slot is `null`. `emotes` and `wraps` are lists in slot order, without the empty slots.
- The data comes from the Fortnite Locker Service, so it changes as soon as the player changes the loadout in the game.

## Images

`icon`, `small_icon` and `featured` point straight to the fortnite-api.com CDN. `icon` has a transparent background.

`background` is the rarity background, the square the game draws behind the item. To build an inventory card, draw `icon` on top of `background`:

```html
<div class="card" style="background-image: url(ITEM.images.background); background-size: cover">
  <img src="ITEM.images.icon" alt="ITEM.name">
</div>
```

The backgrounds are served by the API itself at `GET /backgrounds/{name}.png`, without an API key and with a one-week cache header. The names are `common`, `uncommon`, `rare`, `epic`, `legendary`, `mythic`, `icon-series`, `dark-series`, `star-wars-series`, `marvel-series`, `dc-series`, `gaming-legends-series`, `shadow-series`, `slurp-series`, `lava-series`, `frozen-series`, `crew-series` and `series` (for series that have no square of their own). Mythic items, OGs included, get `mythic`. Crew items get `crew-series`, even though their `rarity` is a plain one like `Epic`.

<Note>
  The `background` URL uses the host the request came in on. Behind a proxy that changes the host, set the `PUBLIC_URL` environment variable (for example `https://api.yourdomain.com`).
</Note>

For a ready-made locker image, use `POST /render/{category}`, with `category` set to `skins`, `backpacks`, `pickaxes`, `gliders`, `emotes` or `mythics`. `mythics` gathers the mythic items of all those categories, outfits first. It returns a PNG with a header (category icon, "LOCKER" or "ARMÁRIO", category name with the count and how many are from the shop, Epic Games logo, nickname and date) and a grid with one card per item, with the rarity background and the name.

The route does not use a session. Send the items you saved from `/locker`: you can render the image again at any time, without a new login.

```bash
curl -X POST https://api.yourdomain.com/render/skins \
  -H "X-API-Key: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"display_name": "Player123", "items": [{"id": "cid_028_athena_commando_f", "owned_styles": ["Mat3"]}]}' \
  -o skins.png
```

- You can send the items of every category together: only the requested category goes into the image.
- Send `owned_styles`: without it, OGs (Renegade Raider, Ghoul Trooper, Skull Trooper…) are not recognized.
- `"language"` sets the language of the whole image: `en` (default) gives "LOCKER", "SKINS", "BACK BLINGS", "PICKAXES"… and the English item names; `pt-BR` gives "ARMÁRIO", "TRAJES", "ACESSÓRIOS PARA AS COSTAS", "FERRAMENTAS DE COLETA"… and the Portuguese item names.
- Without any item of the category, the response is `422`.
- Large accounts are scaled down to fit 2048 px of width. The first image of a large account can take a few seconds, because the icons are downloaded and then cached.

<Tip>
  Cache the downloaded images locally by `id`. But only cache them when the response is `200`: newly released items may not have an image yet.
</Tip>

## New items

When Epic releases a skin, it shows up in the locker as soon as the player owns it, because the list comes straight from the account profile. Name, rarity and image depend on fortnite-api.com:

- If the item is not in the in-memory catalog yet, the API fetches just that item on demand.
- If fortnite-api.com does not have the item yet, it comes with `in_catalog: false`, `name` equal to `id` and `rarity: "Common"`. Show a placeholder in that case.

---
title: "Errors"
description: "HTTP codes returned by the API and how to handle each one in the bot."
icon: "triangle-exclamation"
---

Every error has the same shape:

```json
{ "detail": "Session is pending" }
```

| Code | When it happens | How to handle it |
|---|---|---|
| `401` | `X-API-Key` header missing or wrong | Check the bot's environment variable |
| `404` | The `session_id` does not exist: it never existed, was ended with `DELETE` or expired from inactivity | Ask for a new login |
| `409` | `/summary` or `/locker` was called before the login finished | Wait for `status: completed` in `GET /auth/{session_id}` |
| `410` | The Epic token expired (~2 h after the login) | Ask for a new login |
| `422` | Invalid parameter, or `POST /render/{category}` got no item of the category | Fix the call |
| `502` | Epic Games returned an error | Try again. If it persists, the account may be banned or Epic may have changed something |

<Note>
  A `502` on `POST /auth/device` usually means Epic rejected the client ID used for the login. Check the API logs for details.
</Note>
